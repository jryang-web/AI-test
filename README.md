## 報修清單篩選

清單上方新增「全部／高／中／低」按鈕，預設為「全部」，目前選項以深綠底色與底線標示。「高」緊急程度標籤以紅色顯示。篩選僅套用網頁已載入的最近 20 筆報修，不額外查詢資料庫；重新整理清單後保留目前篩選。沒有符合資料時顯示提示。本次未變更資料庫、欄位或 supabase 資料夾。

手機驗證：依序點選各篩選按鈕，確認只顯示對應緊急程度、選取樣式切換、紅色高緊急標籤，以及「全部」可恢復清單。
